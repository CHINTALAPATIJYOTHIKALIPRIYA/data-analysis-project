
# E-Commerce Sales Analysis

## Project Overview
This project focuses on analyzing an e-commerce sales dataset to understand sales performance, profitability, and business trends. The analysis helps identify top-performing products, profitable categories, and regional sales performance.

## Tools and Technologies
- Python
- SQL
- SQLite
- Microsoft Excel
- Power BI

## Project Objectives
- Analyze overall sales and profit.
- Identify top-performing products and categories.
- Understand the impact of discounts on profit.
- Compare sales and profit across different regions.
- Identify loss-making sub-categories.

## Analysis Performed
- Explored and analyzed the sales dataset.
- Used SQL queries to summarize sales and profit.
- Examined product and category performance.
- Analyzed the relationship between discounts and profit.
- Created charts to present important findings.

## Project Files
- `DataAnalyst.ipynb` – Python analysis.
- `SQL_Queries.sql` – SQL queries.
- `Ecommerce_Analysis_Project.xlsx` – Excel workbook.
- PNG files – Visualizations of the analysis.

## Key Insights
The analysis explores which products and categories perform well, how discounts relate to profitability, and how business performance varies across regions.

## Conclusion
This project helped me gain practical experience in data analysis using Python, SQL, SQLite, Excel, and Power BI. It also helped me understand how data can be used to identify business trends and support better decision-making.
